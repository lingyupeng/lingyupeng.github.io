# Lingyu Peng — Academic Portfolio

A personal academic website featuring publications, art papers, and selected interactive design projects.

Built with Vite, React, Motion, and CSS. The site is deployed automatically to GitHub Pages through GitHub Actions.

## 本地运行

```bash
npm install
npm run dev
```

## Content

Profile information, publications, paper abstracts, and portfolio projects are maintained in `src/content.js`.

## GitHub Pages

Every push to the `main` branch triggers the workflow in `.github/workflows/deploy.yml` and publishes the production build.
